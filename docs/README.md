# Documentacao Tecnica

Indice dos documentos criados para catalogar e desenhar o projeto.

| Documento | Conteudo |
| --- | --- |
| `catalogo-projeto.md` | Estrutura, dependencias, variaveis de ambiente, modulos e dividas tecnicas |
| `arquitetura.md` | Diagramas Mermaid de arquitetura, autenticacao, consultas e fronteiras de seguranca |
| `catalogo-api.md` | Catalogo das rotas da API, parametros e finalidade |
| `boas-praticas.md` | Checklist e padroes recomendados para evoluir o projeto |

## Como usar

1. Antes de alterar uma area, consulte o modulo correspondente no catalogo.
2. Antes de criar rota nova, siga o checklist em `boas-praticas.md`.
3. Ao adicionar ou alterar endpoints, atualize `catalogo-api.md`.
4. Ao mudar fluxo, banco, autenticacao ou infraestrutura, atualize `arquitetura.md`.
